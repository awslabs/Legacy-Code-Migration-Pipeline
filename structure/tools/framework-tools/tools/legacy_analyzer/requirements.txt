# Language-Specific Analysis
# -------------------------
# The legacy analyzer includes parsers for:
# - COBOL (dependency extraction, complexity analysis)
# - PL/I (include analysis, procedure calls)
# - JCL (job dependencies, dataset references)
# - REXX (program calls, dataset access)
# - Natural (using analysis, program calls)
# - RPG (program calls, file access)
# - Assembler (macro calls, program references)
#
# All parsers use only Python standard library features for maximum compatibility.

# Analysis Capabilities
# --------------------
# - Static code analysis across multiple mainframe languages
# - Dependency extraction and validation
# - Complexity metrics (LOC, cyclomatic complexity, dependency counts)
# - Flow analysis (entry points, call graphs, circular dependencies)
# - Missing code detection
# - CICS metadata integration
# - Migration package planning
# - Comprehensive reporting (text, JSON, CSV, HTML, markdown)
