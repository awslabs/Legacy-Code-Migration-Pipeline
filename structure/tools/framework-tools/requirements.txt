# Tool-Specific Dependencies
# -------------------------
# The following dependencies are included from individual tool requirements:

# From tools/smf-analyzer/requirements.txt:
# - All SMF parsing, loading, and querying dependencies
# - Database adapters and schema management
# - SMF documentation parsing utilities

# From tools/legacy-analyzer/requirements.txt:
# - Static code analysis dependencies
# - Multi-language parser support (COBOL, JCL, PL/I, etc.)
# - Complexity analysis and flow visualization
# - Migration package planning utilities

# From tools/migration-planner/requirements.txt:
# - Future AI/LLM integration dependencies
# - Migration planning and code generation tools
# - Rules extraction and transformation utilities

# Installation Notes
# -----------------
# For minimal installation (core functionality only):
#   pip install -r requirements-minimal.txt
#
# For full installation (all tools and features):
#   pip install -r requirements.txt
#
# For development (includes testing and code quality tools):
#   pip install -r requirements-dev.txt
#
# For individual tool installation:
#   pip install -r tools/smf-analyzer/requirements.txt
#   pip install -r tools/legacy-analyzer/requirements.txt
